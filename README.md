# 安踏集团多维敏捷网球鞋 · Powered by ALAB

由附件「3d打印网球鞋 单只鞋.blend」制作的 Three.js 交互网站。

在线体验：[GitHub Pages](https://al7755260-jpg.github.io/alab-tennis-shoe-explorer/)

项目仓库：[al7755260-jpg/alab-tennis-shoe-explorer](https://github.com/al7755260-jpg/alab-tennis-shoe-explorer)

## 打开网站

Windows：双击「打开网站.cmd」。脚本在后台启动本地网站并打开浏览器。

需要 Node.js 20.19+ 或 22.12+。当前电脑已具备 Node.js。发布版已构建完成，启动时不需要安装 npm 依赖、不需要联网。

也可以在此文件夹执行 `node server.mjs`，然后打开 http://127.0.0.1:4187 。启动脚本会检查网站身份，端口被其他程序占用时自动选择其他可用端口。

请通过本地服务打开，浏览器直接双击 HTML 文件无法正常加载 GLB / WebAssembly。

## 操作

- 初次进入：播放约 11 秒的粒子波动成型动画，从鞋底向上逐层显现。生成边界带有缓慢流动的随机液态起伏，颗粒、碎块和流线沿同一条不规则边界汇聚成实体；可点击“跳过动画”。
- 完整鞋体状态下，右上角“重播成型”可再次播放入场动画；展开后隐藏此入口，避免意外合拢。
- 成型后轻点鞋身：10 个真实零件沿连续曲线同步展开，位移与倾斜一气呵成。完整展开后围绕中心零件慢速公转，并各自慢速自转；进入特写时固定当前姿态，返回爆炸图后继续转动。
- 左右拖动或滑动：直接跟手旋转，松手后短暂滑行；上下拖动可以俯仰查看。
- 展开后轻点任一零件：相机平滑推进查看细节，选中的零件保持真实材质；其余零件变为由下向上循环生长、沿表面聚散的细小噪波颗粒，不绘制半透明实体外壳或长线拖尾。
- 直接点击其他零件的粒子轮廓，可以切换查看对象；原先选中的实体沿同一套生长噪波边界反向消散成粒子，约 2.7 秒完成（当前零件生长的两倍速度）。新选中的零件沿用开场的粒子汇聚、液态噪波边界及由下向上的成型效果，以开场 2 倍速度、约 5.4 秒恢复实体。完成后恢复精细几何与 PBR 材质。
- 首次从爆炸图进入特写时保留当前实体；再次点击正在查看的零件或调整窗口大小不会重播。生成期间可以继续旋转或直接改选其他零件，新选择会立即接手动画；返回爆炸图和复位都会取消未完成的生成。
- “返回爆炸图”：退出特写，保持展开。右上角“复位”会让 10 个零件统一从细颗粒噪波长回实体，同时平滑移动、旋转归位，约 5.4 秒完成。成型、归位和镜头共享进度；期间不重复触发，结束后恢复完整鞋体与默认视角。
- 总览隐藏名称和连线；进入零件特写后，仅所选零件显示名称及半透明白色连线，随旋转、缩放动态跟随。
- 滚轮 / 双指：缩放。
- 键盘：焦点在模型时，回车 / 空格展开，左右方向键旋转，加减号缩放；Tab 可访问按钮。

拖动与轻点分别判断，多指操作不会触发点击。尊重系统减少动态效果偏好：跳过粒子入场，立即展示完整鞋体；特写时保留静态颗粒轮廓，停止循环生长动画。

## 模型与文件

- `public/models/tennis-shoe.glb`：精细模型，约 2.75 MB，10 个网格节点，约 108.5 万三角面，进入特写后按需加载。
- `public/models/tennis-shoe-preview.glb`：静止预览模型，约 31.6 万三角面，用于整体静止展示；特写时未选中实体隐藏并保留点击检测。
- `public/models/tennis-shoe-intro.glb`：轻量模型，约 11.4 万三角面，用于成型、拖动、缩放及相机动画。停止运动后自动恢复细节。
- `public/models/print-samples*.bin`：从原始鞋体表面预计算的粒子位置、法线和随机种子，按高度排序，开场直接读取。
- `public/models/focus-samples*.bin`：按零件分别预计算的表面粒子，桌面总预算 36000、窄屏总预算 18000，约 1.01 / 0.51 MB；选中零件的粒子不绘制。
- `public/models/parts.json`：原始物体名称和网格统计。
- `src/parts.js`：各零件的展开方向与距离。
- `src/explode-layout.js`：连续展开曲线、围绕中心的公转及各零件自转；复位恢复原始位置及旋转。
- `src/main.js`：Three.js 场景、鼠标 / 触屏交互、动画与取景。
- `src/render-quality.js`：预热并缓存运动期间的轻量几何、材质和光照，停下后恢复精细模型与 PBR 材质。
- `src/print-intro.js`：预计算数据加载、GPU 粒子波动、流线及由下向上的成型材质。
- `src/print-effect.js`：开场和零件切换共用的粒子汇聚、切片成型着色器及速度参数（10800ms / 2）。
- `src/focus-noise.js`：零件特写时的 GPU 生长与反向消散噪波、粒子资源复用及零件切换。
- `src/studio.js`：带柔和炭黑渐变层次的摄影棚背景及灯光，没有地面或阴影平面。
- `src/style.css`：桌面与手机布局。
- `dist/`：可以部署到静态网站服务器的完整文件。

从源文件中选取同一位置的完整精细鞋体（01–08、10、11）；编辑控制网格与另行摆放的 SubD 副本未重复加入网页。未修改或覆盖原始 Blender 文件。

精细模型保留源面数并使用 Draco 高精度量化压缩，预览模型单独减面。白色鞋面、底部网格纹路、孔位和绿色嵌件都来自附件。网页使用自己的摄影棚灯光，材质观感会与 Blender 的光照略有差别。零件名称中带数字的标签用于对应源物体，不代表工程制造定义。

完整鞋体静止时停止重复绘制；爆炸图公转与自转持续绘制轻量几何，零件特写时暂停公转并持续绘制生长噪波，退出特写后恢复公转。拖动直接响应输入，不使用拖动过程中的阻尼追赶；惯性仅在松手后短暂生效。运动期间使用缓存的轻量模型与摄影棚近似光照，停止约 160ms 后恢复 PBR 材质；选中零件恢复原始精细几何。两套渲染材质在开始交互前预热，拖动时不临时创建材质或解码模型。运动开始时使用约 85% 的渲染比例；持续低帧率时分档降至 82% / 67%，每次判断至少 45 帧并间隔 1.8 秒，避免逐帧改变缓冲。完整鞋体静止后恢复完整画布分辨率；持续粒子特写沿用已测得的设备预算，但始终保留选中零件的原始精细几何。画布像素比上限为 1，总像素预算约 120 万，文字和标注保持浏览器原生分辨率。

入场动画使用桌面 18000 / 窄屏 9000 个 GPU 粒子及少量实例化碎块、流线；只绘制活跃高度区间的粒子，跳过尚未生成的零件。播放前完成着色器编译、几何上传与首帧预热。动画期间使用轻量光照并自适应渲染分辨率，结束后释放入场粒子几何和临时材质。轻量鞋体几何与采样数据保存在内存中供运动与重播复用。

特写噪波使用单独的缓存粒子系统：进入网页时读取表面采样并预热着色器，点击时仅切换可见对象，GPU 根据少量时间参数计算聚散；不逐帧遍历三角面或改写粒子缓冲。非选中零件的实体完全不参与绘制，使用独立的 BVH 加速预览网格进行点击检测，避免粒子变稀时难以选中。静止噪波不会反复更新名称连线的 DOM 布局。返回爆炸图时恢复所有实体并停止噪波绘制；复位时全体零件同步噪波成型并合拢。性能因设备而异，窄屏浏览器检查不等同于实际手机帧率测试。

切换时直接复用该零件的粒子与两套预热材质，不重新采样、创建粒子或编译着色器。实体裁切和粒子汇聚共用 GPU 平滑噪波场，生成边界呈圆润的波峰与凹谷，成型结束时平滑收束，避免残留缺口。噪波只在生成边界附近计算；入场粒子的高度裁剪同时包含波动幅度。生成光带随零件的实际高度缩放，并跟随爆炸图中的位置；生成期间使用轻量几何，结束后恢复完整细节。时间计算包含限帧时跳过的 RAF 间隔，避免高刷新率屏幕把 5.4 秒动画拉长；页面进入后台时暂停。

消散将同一生成进度反向播放，实体切口和粒子释放由同一噪波场控制。快速连续切换时，各旧零件完成自己的消散；尚未成型的零件从当前缺口反向退去，不闪回完整实体。返回爆炸图会取消所有消散；复位会取消局部切换并启动所有零件统一成型。减少动态效果模式直接切换并停止公转、自转。

统一复位复用现有粒子与预热材质，以同一个进度控制每个零件的成型前沿。每帧同步粒子变换与裁切空间，颗粒和切口始终跟随移动中的零件，不留在展开位置。记录复位瞬间的姿态并平滑插值到原始位置、旋转；成型完成时隐藏所有粒子、关闭裁切，恢复静止渲染。展开总览、零件特写、切换动画中途和完整鞋体状态均可使用复位。

公转采用共同旋转的轨道，各零件自转只绕竖直轴，保持高度区间。按完整原始几何计算的旋转包络互不相交。展开路径经过三角面采样检查：合拢的原模型本身存在重叠面，起步分离阶段约前半秒仍有这些接触；20% 至 100% 的已测展开位置无三角面相交。未改写模型拓扑来消除源文件中的重叠面。

为了让持续噪波与精细零件同时运行，绿色嵌件使用保留原色、粗糙度与精细几何的实体 PBR 近似，不启用源材质约 9.5% 透射所需的额外渲染；原始模型文件及其材质参数仍完整保留。

## 继续编辑

```sh
npm install
npm run dev
```

重新构建：`npm run build`。发布时上传 `dist` 中的内容；模型、Draco 解码器与脚本都已本地化，无 CDN、无外部字体、无分析追踪。

GitHub Pages 从 `main` 分支的 `docs/` 目录发布。更新网站时运行 `npm run build:pages`，将源码与生成的 `docs/` 一起提交并推送；等待 GitHub 的 Pages 部署成功后，线上网站才会更新。Vite 使用相对资源路径，适配仓库子路径访问。

参考文档：[Three.js](https://threejs.org/docs/)、[OrbitControls](https://threejs.org/docs/pages/OrbitControls.html)、[GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html)。

展开总览、公转、复位期间隐藏所有 callout 名称与连线；点击零件后只显示所选零件的一条标注，随相机更新。返回总览立即隐藏，避免十条连线交叉及总览动画期间的 SVG/DOM 更新。

粒子采样保持同一套原始表面位置、法线和种子，仅在离线烘焙时按高度排序。成型时通过保守噪波边界和二分查找缩短绘制区间，跳过已经转为实体的颗粒；切换/复位会正确恢复区间。共享噪波前沿只计算一次，视锥外粒子组不提交绘制。材质切换复用已编译程序，不再无条件标记重新编译。

拖动和惯性阶段同样采用约 60Hz 的绘制预算；输入事件仍即时更新相机，下一帧使用最新位置，避免高刷新率设备在拖动时额外堆积 GPU 工作。开发环境的观测字段最多每 120ms 更新一次，不影响正式版的渲染。

点击检测使用预先构建的 BVH 空间索引及最近命中查询，沿用真实预览网格而非包围盒，保留镂空和零件轮廓。显示模型切换细节等级或变成粒子后，命中模型依然有效；公转和复位使用实时世界矩阵。索引在加载期间分零件构建，不在点击事件内计算，且不重排原始渲染索引。短暂松手后保留运动渲染预算约 500ms，避免连续拖动时反复重建画布缓冲。

验证：`npm test` 检查命中顺序、变换、隐藏粒子态、细节等级切换和画布缓冲稳定性；`npm run build:pages` 生成线上版本。
